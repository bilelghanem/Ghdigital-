# GHDigital — Digital Products Store

Bilingual Arabic/English responsive storefront prototype for digital products.

## Files
- `index.html` — storefront structure and Arabic/English content
- `styles.css` — responsive dark theme styling
- `app.js` — demo product cards, search, category filters, language switch
- `assets/logo.svg` — editable vector logo

## Current status
This is a **front-end prototype only**. Product listings and prices are sample content. The newsletter form is a demo and does not submit data. Product buttons do not sell or deliver files. No payment provider, customer database, admin dashboard, order tracking, or secure downloads are configured.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then Save.
5. Wait for the deployment and open the Pages URL shown there.

## Before accepting real payments
Build and deploy a trusted server-side backend, order database, protected file storage, secure expiring download links, email delivery, admin authentication, and server-side payment verification/webhook handling. Never expose secret API keys in browser code or a public repository. Confirm that the chosen payment provider supports your business and country before relying on it.

## Product content
Replace demo product names, prices, artwork and descriptions with your own licensed/original products before launch.
